AI & COMPUTER VISION SPECIFICATION ARCHITECTURE SPECIFICATION & PRODUCTION DEMO

Smart Gesture Slide Controller (Touchless AI Presentation System)

Practical On-Device Computer Vision architecture: Utilizing MediaPipe Hands for real-time 3D landmark tracking paired with a 3-layer Anti-False-Positive Finite State Machine, empowering presenters with complete stage freedom.

4-STAGE END-TO-END SYSTEM ARCHITECTURE PIPELINE < 25ms Total Frame Time
STAGE 01 · INGESTION
Webcam HTML5 Stream

60FPS video capture & mirrored Canvas HUD rendering

STAGE 02 · EXTRACTION
MediaPipe 21-Joint 3D

Extracts normalized 3D coordinates (X, Y, Z) per hand

STAGE 03 · GEOMETRY
Euclidean Classifier

Computes Tip-to-Wrist vs. PIP-to-Wrist distance ratios

STAGE 04 · DEBOUNCER
3-Layer FSM Engine

Master Lock 1.0s → Dwell 800ms → Cooldown 1.2s

CORE OBJECTIVES & ARCHITECTURAL BREAKTHROUGHS
  • Ultra-fast On-Device Processing (30–60 FPS): Tracks 21 3D hand joints directly in the browser via WebCam with MediaPipe Hands, zero cloud video transmission, 100% privacy, and sub-25ms response latency.
  • 3-Layer Anti-False-Positive Engine: Eliminates accidental slide jumps during natural speaking gestures via Master Lock (Open Palm 1.0s), Hold-to-Trigger (800ms dwell with SVG progress ring), and a 1.2s Cooldown Buffer.
  • Touchless Stage Experience: Features glowing Virtual Laser Pointer (Pinch gesture) and Global Two-Hand Zoom (1.0x – 2.5x), removing dependency on handheld hardware clickers.

Technical Module Specifications

Mathematical geometry and Finite State Machine (FSM) breakdown behind the system

Initializes HTML5 webcam streams rendered directly onto an HTML5 Canvas. The MediaPipe Hands on-device pipeline separates palm bounding boxes and accurately tracks 21 spatial landmarks (X, Y, Z) at 30–60 FPS.

// On-Device Computer Vision & Skeleton Tracking:
Webcam Video (HTML5) → MediaPipe Hands (Palm Detection) → 21 3D Landmarks (X, Y, Z)
Render: Mirrored Canvas HUD (30-60 FPS) • Latency < 25ms • 100% Client-side Privacy

Computes Euclidean distances between fingertips (Tip) and intermediate joints (PIP/MCP) relative to the wrist to determine finger extension states: Single Index (☝️ Next), Peace Sign (✌️ Prev), Pinch (🤏 Virtual Laser), and Inter-palm distance (👐 Zoom 1.0x – 2.5x).

// Geometric Gesture Classification Logic:
Finger Fold/Extend = EuclideanDistance(FingerTip, Wrist) vs EuclideanDistance(PIP, Wrist)
Gesture Mapping: [☝️ Index Up = Next, ✌️ Peace = Prev, 🤏 Pinch = Laser, 👐 2-Hands = Zoom]

3-layer protection: Layer 1 - Master Lock (Open Palm held for 1.0s) toggles ACTIVE ⟷ LOCKED state; Layer 2 - Hold-to-Trigger requires 800ms continuous dwell with an animated SVG charge ring (accidental hand waves immediately cancel); Layer 3 - 1.2s Cooldown Buffer locks transition events to prevent slide bounce.

// 3-Layer Anti-False-Positive State Machine:
Layer 1: Master Lock [🖐️ Open Palm held 1.0s] → Toggle (ACTIVE ↔ LOCKED)
Layer 2: Hold-to-Trigger [Dwell Time 800ms + SVG Charge Ring] → Accidental waves reset to 0%
Layer 3: Cooldown Buffer [1200ms lock-out] → Slide Bounce Protection
ENGINEERING TRADE-OFFS & EMPIRICAL CONSTRAINTS

Why Euclidean Geometric Heuristics instead of a Deep Classifier (MLP/CNN)?

Once MediaPipe extracts 21 3D landmarks, scale-invariant Euclidean distance ratios require near-zero CPU overhead (<0.2ms), preserving a smooth 30–60 FPS on standard student/classroom laptops without dedicated GPUs.

Empirical Operating Constraints & Future Work:

Operates reliably at 0.5m – 2.2m camera distance under standard indoor lighting. Future iterations will integrate a 1€ Filter (One-Euro Filter) to further reduce jitter on the virtual laser pointer under low-light webcam sensor noise.
