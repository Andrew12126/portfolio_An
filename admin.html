Cài Đặt GitHub Access Token

Để có thể lưu trực tiếp thông tin từ điện thoại hoặc máy tính lên website đang chạy thực tế, bạn chỉ cần dán GitHub Token (Classic) vào đây một lần duy nhất.

Cách lấy mã Token trong 30 giây:
  1. Vào GitHub: github.com/settings/tokens
  2. Bấm Generate new token (classic)
  3. Mục Note: đặt là Portfolio-Admin
  4. Mục Select Scopes: Tích chọn đúng 1 ô duy nhất là repo
  5. Bấm Generate token ở cuối trang rồi sao chép chuỗi ghp_... dán vào ô bên dưới.

🔒 Mã token chỉ được lưu cục bộ trong bộ nhớ trình duyệt máy bạn (localStorage), không ai khác thấy được.
